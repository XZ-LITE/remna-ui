# Remnawave UI (Deployment & Manager Suite)

Нативное десктопное приложение для Windows 10/11 для автоматизированного развертывания, тонкой настройки, защиты от блокировок и мониторинга экосистемы **Remnawave** (Master-панель + Xray Reality Nodes).

## Ключевые возможности

### 1. Развертывание в 1 клик (Zero-Touch Deployment)
- **Все включено (Full Stack)**: Автоматическая установка на чистый VPS мастер-панели Remnawave, базы данных PostgreSQL, Valkey (Redis) и подключение ноды Xray Reality.
- **Мастер развертывания нод**:
  - **Режим «Под ключ (Все включено)»**: автоматическая регистрация ноды через REST API панели, генерация VLESS Reality профиля, создание публичного хоста подписки в разделе «Подписка» → «Хосты» и добавление в дефолтный сквад пользователей. Нода сразу готова к выдаче клиентам.
  - **Режим «Использовать существующий профиль»**: опрашивает панель, выводит интерактивные списки существующих профилей Xray и сквадов пользователей, позволяя администратору прикрепить ноду к существующей архитектуре без создания дубликатов.
  - **Режим ручного ввода**: ввод готового `SECRET_KEY` для нод, созданных вручную в веб-интерфейсе.

### 2. Защита от цензуры и ТСПУ (Anti-Probing & Stealth)
- **Изоляция порта связи в `DOCKER-USER`**: Docker перехватывает порты до цепочки `INPUT`. Программа внедряет правила в самое начало цепочки `DOCKER-USER`, разрешая доступ к порту ноды (2222) **только** с IP-адресов мастер-панели. Любые внешние сетевые сканеры блокируются.
- **Политика Stealth DROP**: сброс неавторизованных пакетов без отправки `TCP RST`, что скрывает наличие активного сервера от активного зондирования ТСПУ / GFW.
- **Маскировка SelfSteal Decoy**: перенаправление неавторизованных HTTP/HTTPS запросов на локальный веб-сервер с реальным Let's Encrypt сертификатом.
- **Анти-абуз защита**: автоматическая блокировка `geoip:private` (защита от SSRF), протокола BitTorrent (защита от DMCA-жалоб) и почтовых портов 25/465/587 (защита от спам-ботов).

### 3. Менеджер серверов и мониторинг VPS
- **Панель управления всеми серверами**: просмотр статусов Master и привязанных к ним Node в виде дерева связей.
- **Телеметрия в реальном времени**: опрос загрузки оперативной памяти (RAM), процессора, дискового пространства и пинга серверов.
- **Управление Docker-стеком**: просмотр статуса каждого контейнера (`remnawave`, `remnanode`, `caddy`, `postgres`), перезапуск отдельных служб или всего стека в 1 клик.
- **Просмотр логов в реальном времени**: просмотр логов любого контейнера с поиском и авто-обновлением.
- **Резервное копирование и восстановление**: создание полных архивов базы данных и конфигурации, скачивание и откат из бэкапа.
- **Сервисные утилиты**: оптимизация TCP BBR, настройка зеркал Docker Registry, авто-исправление синхронизации базы данных и токенов подписки.

### 4. Безопасность и архитектура
- **Шифрование DPAPI**: учетные данные серверов (пароли SSH, приватные ключи, пароли суперпользователя) шифруются системным криптографическим провайдером Windows (`CryptProtectData`) перед сохранением в `%APPDATA%\remnawave\servers.json`.
- **Нативный интерфейс WinUI 3**: дизайн в стиле Windows 11 с поддержкой темной/светлой темы, эффекта акрилового стекла Mica, плавными Fluent-анимациями (cubic-bezier deceleration) и батчингом логов развертывания с частотой 60 кадров/сек.

## Сборка из исходников

### Требования
- **ОС**: Windows 10/11 (x64)
- **Go**: версия 1.22 или выше ([golang.org](https://golang.org))
- **Node.js**: версия 20.x или выше ([nodejs.org](https://nodejs.org))
- **Wails CLI**: `go install github.com/wailsapp/wails/v2/cmd/wails@latest`

### Инструкция по сборке

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/XZ-LITE/remna-ui.git
   cd remna-ui
   ```

2. Установите зависимости фронтенда:
   ```bash
   cd frontend
   npm install
   cd ..
   ```

3. Запустите в режиме разработки (Hot Reload):
   ```bash
   wails dev
   ```

4. Соберите релизный автономный бинарник:
   ```bash
   wails build -clean -s
   ```
   Скомпилированный файл будет находиться по пути: `build/bin/remna-ui.exe`.
